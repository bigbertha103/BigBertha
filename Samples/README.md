# Samples Entreprises

Ce dossier contient des entreprises fictives multi-secteurs pour tester:
- l'orchestration Boss/Agents,
- l'apprentissage sectoriel (RAG + SENTINEL),
- la robustesse sur formats hétérogènes.

Formats inclus par entreprise:
- `.md` (profil, FAQ, article, liens hypertextes)
- `.txt` (problématiques terrain)
- `.pdf` (rapport KPI synthétique)
- `.docx` (procédure opérationnelle)
