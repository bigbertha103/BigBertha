## Comment utiliser cet index

- **Mission technique** → lire `Tech/architecture.md`
- **Mission produit / pitch** → lire `Produit/vision.md`
- **Doute sur un terme** → lire `langage.md`
- **Décision déjà prise** → vérifier `elements_figes.md` avant de proposer quoi que ce soit

## Règles de mise à jour

1. Tout fichier BASE a un en-tête `last_updated` et un `owner`
2. Format obligatoire : markdown uniquement
3. Taille max : 2 pages (~100 lignes)
4. Pas de nouveau fichier sans vérifier que l'info n'existe pas déjà
5. Le prompt de clôture (`docs/Prompt/session_closure.md`) met cet index à jour automatiquement
