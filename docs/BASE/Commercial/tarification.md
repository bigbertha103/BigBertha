## Statut

Modèle commercial en cours de réflexion. La grille ci-dessous est un **brainstorm validé comme direction — aucun prix figé à ce stade.**

## Modèle commercial

Vente B2B. Une instance par client (mono-tenant). Pas de SaaS multi-tenant.

Vision finale : bundle software + machine dédiée, tout local chez le client.
Phase de test/dev actuelle : LLM via OpenRouter (coût opérationnel OpenRouter à préciser dans les conditions).

## Grille tarifaire — 3 paliers

| Palier | Techno LLM | Pôle ciblé |
|---|---|---|
| **Basique** | OpenRouter (cloud US) | Personnalisation/contexte + performance accessible |
| **Premium** | Serveur français mutualisé | Sécurité / souveraineté / RGPD |
| **Performance+** | Serveur français isolé (non mutualisé) | Performance + Sécurité combinés |

## Questions ouvertes (à traiter avant de figer)

- La personnalisation profonde des agents est-elle transverse aux 3 paliers, ou limitée au Basique ?
