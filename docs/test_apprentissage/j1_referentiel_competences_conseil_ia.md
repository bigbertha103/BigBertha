# Référentiel de compétences — Consultant IA Neuraltech 2026

## Objectif
Ce référentiel définit les compétences attendues pour les consultants de Neuraltech Consulting, structurées en 4 niveaux (Junior, Confirmé, Senior, Expert). Il sert de base aux recrutements, aux évaluations annuelles et à la constitution des équipes projet.

## Domaine 1 — Fondamentaux LLM

| Niveau | Compétences attendues |
|---|---|
| Junior | Comprend les notions de prompt engineering, tokenisation, fenêtre de contexte, température. |
| Confirmé | Sait choisir un modèle selon le cas d'usage (taille, langue, licence). Maîtrise le few-shot prompting. |
| Senior | Maîtrise le fine-tuning supervisé et le RLHF conceptuellement. Connaît les architectures MoE et les trade-offs. |
| Expert | Conçoit une stratégie de modèles pour un SI complexe (routing, fallbacks, gestion des coûts d'inférence). |

## Domaine 2 — Architecture RAG

| Niveau | Compétences attendues |
|---|---|
| Junior | Comprend le pipeline RAG : découpage, embedding, recherche vectorielle, génération. |
| Confirmé | Implémente un RAG basique avec LlamaIndex ou LangChain sur des documents texte. |
| Senior | Optimise les paramètres (chunk size, overlap, top_k, re-ranking). Intègre le RAG dans un pipeline données client. |
| Expert | Conçoit des architectures RAG hybrides (dense + sparse) avec évaluation automatisée (RAGAS, TruLens). |

## Domaine 3 — Agents IA

| Niveau | Compétences attendues |
|---|---|
| Junior | Comprend la notion d'agent : LLM + outils + mémoire. Connaît les patterns ReAct et CoT. |
| Confirmé | Construit un agent mono-tâche avec LangGraph ou CrewAI. Gère les outils et les erreurs. |
| Senior | Conçoit des systèmes multi-agents avec handoffs et orchestration. Évalue les performances. |
| Expert | Évalue les trade-offs entre architectures agents (réactivité vs planification, coûts d'inférence). |

## Domaine 4 — Conduite de projet IA

| Niveau | Compétences attendues |
|---|---|
| Tous | Identifie les risques d'un projet IA : qualité des données, conformité IA Act, résistance au changement. |
| Confirmé+ | Anime un atelier de qualification des besoins IA avec un interlocuteur non-technique. |
| Senior+ | Rédige un business case ROI pour un projet d'agents IA, avec hypothèses documentées. |
| Expert | Pilote un programme multi-projets IA, arbitre les priorités, gère les dépendances. |

## Domaine 5 — Conformité et gouvernance IA

- Tous niveaux (à partir de 2026) : connaît les obligations de l'IA Act pour les systèmes à haut risque.
- Confirmé+ : sait identifier si un système IA est classé haut risque et quelles exigences s'appliquent.
- Senior+ : accompagne un client dans la mise en conformité IA Act (documentation, traçabilité, audit trail).

## Utilisation du référentiel
- **Recrutement** : grille d'entretien structurée par domaine et niveau.
- **Évaluation annuelle** : auto-évaluation consultant + évaluation manager, 5 domaines notés de 1 à 4.
- **Proposition client** : justification des profils mobilisés dans les propositions commerciales.
